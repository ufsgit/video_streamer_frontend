Discovered Layout Issues & Permanent Fixes
1. HomeView: Brand Header & Button RenderFlex Overflow
RESOLVED

Root Cause: Under narrow viewports (300px) or with 1.5x accessibility font scaling, the brand logo and title in HomeView overflowed by 284px because the inner Row was unconstrained. The "Resume video" button row also collided on high text scale.

- Row(children: [AppLogo(...), SizedBox(width: 10), Text('Meridian Health')]) + Expanded( + child: Row(children: [ + AppLogo(size: 38, iconSize: 20), + SizedBox(width: 10), + Flexible(child: Text('Meridian Health', overflow: TextOverflow.ellipsis, maxLines: 1)), + ]), + )
2. LibraryView: Category Tag Pill & Action Row Overflow
RESOLVED

Root Cause: The colorful category cards in LibraryView contained fixed tag pills (e.g. PHASE 1 · PREPARATION) next to a 44px icon container without Flexible bounds, causing 246px horizontal clipping on 300px displays.

- Container(child: Text(tag, ...)) + Flexible( + child: Container( + child: Text(tag, overflow: TextOverflow.ellipsis, maxLines: 1, ...), + ), + )
3. LoginView: Password Label & Forgot Password Collision
RESOLVED

Root Cause: The header Row above the password field had both static "Password" text and a "Forgot Password?" TextButton without flex wrappers, causing a 176px overflow on narrow phone widths.

+ Flexible(child: Text('Password', overflow: TextOverflow.ellipsis)), + Flexible(child: Align(alignment: Alignment.centerRight, child: FittedBox(child: TextButton(...))))
4. YoutubePlayerView: 3-Second Timer Memory Leak & Api Sync Guard
RESOLVED

Root Cause: Future.delayed created an untracked 3s timer that lived past widget disposal. Additionally, ApiService().updateVideoProgress triggered unmocked background Dio requests on exit.

+ Timer? _fallbackTimer; + @override void dispose() { _fallbackTimer?.cancel(); _subscription?.cancel(); super.dispose(); } + if (widget.enableApiSync) { ApiService().updateVideoProgress(...); }
